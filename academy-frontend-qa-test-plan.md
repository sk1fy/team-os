# План тестирования секции «Академия» (Academy V2) — Frontend QA

**Автор:** Frontend-QA
**Дата:** 2026-07-24
**Область:** веб-фронтенд секции `/academy/*`, полноэкранные режимы (конструктор, плеер, предпросмотр), внешнее обучение `/training/*`, отчёты, распространение.
**Роли:** `owner`, `admin`, `partner`, `employee` + внешний ученик (без учётной записи).
**Флаг:** `VITE_ACADEMY_V2` (при выключенном — legacy `AcademyPage`, редиректы `academy-opus` / `academy-grok`).

## Легенда

- **P1/Blocker** — блокирует сквозной сценарий; **P2** — важно; **P3** — косметика/edge.
- Каждая задача = один проверяемый сценарий; примечание уточняет фокус, предусловие или ожидаемый результат.
- Матрица ширин: **desktop**, **768 px** (tablet), **375 px** (mobile).
- Проверка на каждой странице: отсутствие console error/warning, отсутствие горизонтального скролла body, корректная тема (light/dark).

## Приоритетные сквозные (E2E) маршруты для smoke

1. **Автор:** создать курс с нуля → раздел+урок+контент → тест → предпросмотр → публикация → назначение сотруднику.
2. **Ученик:** «Моё обучение» → продолжить → пройти урок → пройти тест → завершить курс.
3. **Из шаблона:** инстанцировать → отредактировать урок копии → опубликовать (регресс AQA-02/08/09).
4. **Внешний:** создать персональный доступ/кампанию → лендинг → email-код → активация → прохождение → результаты.
5. **Отчётность:** внутренний отчёт + CSV; внешний/партнёрский отчёт по кампании.
